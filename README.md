## Sobre mí

Me gusta trabajar con JavaScript, Node.js y Python, fortalecer mi lógica de programación y desarrollar soluciones tecnológicas que respondan a necesidades reales.

## Proyectos

### 1. Sistema de Gestión de Asistencia SENA

Aplicación web orientada al registro y control de asistencia de los aprendices ADSO del SENA en Dosquebradas, facilitando la administración y consulta de los registros.

**Tecnologías:** HTML, CSS, JavaScript, Node.js y MySQL.

### 2. Sistema de Registro de Vehículos para Peajes

Sistema orientado al registro y control de vehículos que transitan por un peaje, con el propósito de organizar la información y facilitar la consulta de los registros.

**Tecnologías:** según las herramientas utilizadas en el proyecto.

### 3. Sitio Web para una Inmobiliaria

Página web para presentar y promocionar propiedades inmobiliarias, mostrar sus características y precios, y facilitar el contacto de las personas interesadas.

**Tecnologías:** HTML, CSS y JavaScript.

## Tecnologías y herramientas

- HTML5 para estructurar páginas web.
- CSS3 para diseñar y dar estilo a las interfaces.
- JavaScript para incorporar funcionalidades.
- Node.js para el desarrollo del entorno de servidor.
- Python para practicar lógica de programación.
- MySQL para almacenar y consultar información.
- Git y GitHub para controlar versiones y publicar proyectos.

## Cómo visualizar el portafolio

1. Clona el repositorio:

   ```bash
   git clone https://github.com/cannalombia/mi_portafolio.git
   ```

2. Entra en la carpeta:

   ```bash
   cd mi_portafolio
   ```

3. Abre `index.html` en tu navegador para visualizar el portafolio.
